# 第一篇：这个网站是怎么来的

## 起因

一直想有个自己的地方放东西，但又不想被平台的规则管着——不想被限流、不想被删、不想数据不属于自己。

## 做法

最后选了最省钱的一条路：**用 Markdown 写内容，生成静态网页，免费托管在 GitHub Pages 上**。

好处很直接：

- 一分钱不用花
- 网址是自己的（可以绑自己的域名）
- 数据全在自己的 GitHub 仓库里，随时能搬走
- 写文章就是写纯文本，不怕格式乱

## 下一篇写什么

大概会写一篇 Markdown 速查，把常用语法记下来，免得每次都要搜。
