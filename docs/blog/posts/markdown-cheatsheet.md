# Markdown 常用语法速查

写文章只需要记住下面这几条，剩下的可以随时回来查。

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 强调

```markdown
**加粗**
*斜体*
~~删除线~~
```

## 列表

```markdown
- 无序列表
- 第二项

1. 有序列表
2. 第二项
```

## 链接与图片

```markdown
[点我跳转](https://example.com)

![图片说明](../../assets/example.png)
```

图片放在 `docs/assets/` 里，然后在文章里写相对路径引用。**路径一定要以 `../../assets/` 开头**（因为文章在 `docs/blog/posts/` 这一层）。

## 表格

```markdown
| 项目 | 说明 |
| --- | --- |
| 名字 | 随便写 |
```

效果：

| 项目 | 说明 |
| --- | --- |
| 名字 | 随便写 |
| 日期 | 2026-11-24 |

## 提示框

```markdown
!!! note "标题"
    这里写内容，注意要缩进 4 个空格。
```

效果：

!!! note "标题"
    这里写内容，注意要缩进 4 个空格。

## 代码块

用三个反引号包起来，后面写语言名：

````markdown
```python
print("hello")
```
````

## 文章开头的日期

每篇文章最上面那段用 `---` 包起来的东西叫 front matter，是给网站看的：

```markdown
---
date: 2026-11-24
categories:
  - 随笔
---
```

`date` 决定它在文章列表里的排序，别漏。
